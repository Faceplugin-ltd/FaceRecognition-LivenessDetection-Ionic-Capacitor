# Android runtime (customer install)

Place **`facerecognitionsdk.aar`** here after installing `face-recognition-capacitor`:

```text
node_modules/face-recognition-capacitor/android/libs/facerecognitionsdk.aar
```

Download from the [FacePlugin Android Drive folder](https://github.com/Faceplugin-ltd/FaceRecognition-LivenessDetection-Android/releases/tag/latest) (same file as Face-Recognition-LivenessDetection-Android / Flutter / React Native).

Do not commit the AAR.
