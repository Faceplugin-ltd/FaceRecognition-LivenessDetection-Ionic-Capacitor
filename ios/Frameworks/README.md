# ios/Frameworks — same LX runtimes as Face-Recognition-LivenessDetection-iOS

```text
ios/Frameworks/
├── facerecognitionsdk.framework
├── FacePluginSDK.xcframework
├── FacePlugin.xcframework
└── FaceDetect.xcframework
```

Copy from the iOS app repository. Device arm64 only. Then `npx cap sync ios`.

The demo iOS bundle id is `com.faceplugin.facerecognition.app` (same FP1 key as the iOS app).
